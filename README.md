## 👨‍💻 About Me

Hey! I'm **Kamalesh**, a Computer Science student from Tamil Nadu, India. I love tinkering with real-time systems, 3D graphics in the browser, and building apps that solve daily annoyances.

- 🎮 **Game Dev**: Building 3D multiplayer browser shooters with Three.js & Socket.io, and exploring desktop game mechanics with Java / jMonkeyEngine.
- 💡 **AI & Practical Software**: Building computer vision models, RAG chatbots for local docs, and background automation utilities.
- 🤝 **Always open to**: Collaborating on interesting open-source projects, hackathons, or playtesting indie game prototypes.

---
