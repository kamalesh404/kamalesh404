I am **Kamalesh**, a **CS student** from Arcot, Tamil Nadu, India. I build things that run in browsers, phones, and edge devices.

**What I Build:**
- Real-time **multiplayer games** with Three.js, Godot 4, and Socket.io
- **AI/ML systems** with YOLO, OpenCV, LLMs, and RAG pipelines
- **Full-stack web apps** with TypeScript, React, Next.js, and FastAPI
- **Edge AI tools** that run entirely offline with zero cloud dependency

**Currently:**
- Learning **Rust + WebAssembly** for browser-native performance
- Contributing to **open source** projects across multiple ecosystems
- Building **privacy-first AI tools** for developers and students
